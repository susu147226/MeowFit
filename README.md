# 喵尺 MeowFit

一款仅面向 **Windows** 的本地媒体尺寸批量调整工具，用于批量调整**图片、动图与视频**的尺寸，
支持按命名前缀 / 扩展名 / 子文件夹自动分组，整体、分组、单文件三级参数相互覆盖。

全部处理在本机完成，**程序不发起任何网络请求**：不上传素材、不收集遥测、不检查更新、不需账号。
提供 **Portable 绿色版**（解压即用）与 **安装版**（NSIS 安装程序）两种分发形态，功能完全一致。

本仓库为**源码可见的专有软件**。许可条款见 [LICENSE](LICENSE)。

## 支持的格式

| 类别 | 格式 |
| --- | --- |
| 静态图片 | PNG、JPG / JPEG、WebP、BMP、TIFF、AVIF、HEIC / HEIF、ICO、SVG |
| 动图 | GIF、动态 WebP、APNG |
| 视频 | MP4、MOV、MKV、AVI、WebM、M4V、FLV、WMV、MPEG / MPG、TS |

不支持的格式会被跳过并列入报告的「已跳过」清单，不影响其余素材的处理。

## 技术栈

| 层 | 选型 |
| --- | --- |
| 桌面框架 | Tauri 2 |
| 前端 | React + TypeScript + Vite + Tailwind CSS |
| 核心 | Rust（edition 2021） |
| 静态位图 | `image` crate |
| SVG | `resvg` crate |
| 视频 / 动图 | FFmpeg（GPL 构建，独立进程调用） |
| 打包 | Windows NSIS |

## 功能

**素材导入与扫描**

- 选择文件夹、拖拽文件夹、拖拽多个文件、粘贴路径；记住最近使用的文件夹。
- 递归子文件夹（可切换「仅当前层」）、包含 / 排除通配符、扩展名大小写不敏感。
- 自动忽略隐藏文件、系统文件、程序自身目录与输出目录；扫描全程只读。

**缩放方式**

| 编号 | 名称 |
| --- | --- |
| A | 等比缩放（居中） |
| B | 自定义宽高（等比适配 fit） |
| C | 自定义宽高（填满裁剪 cover） |
| D | 自定义宽高（拉伸 stretch） |
| E | 限制最大边 |
| F | 仅放大 / 仅缩小（附加开关） |
| G | 倍数锚点缩放 |

每个可设置位置都支持「缩放倍率」（`2`、`0.5`、`150%`）与「目标宽高」两种输入，
可填算术表达式（`1920/2`、`1280*0.75`）；「按比例自动计算」默认开启，只填一边自动算出另一边，
关闭后只填一边会报错并指明缺少哪一边。

**自动分组与优先级**

- 三种分组方式单选：按命名前缀（默认）、按扩展名、按所在子文件夹。
- 分组结果可见且可手动修正：重命名、跨组移动、合并；切换分组方式会提示修正将被重置。
- 优先级：**单文件 > 分组 > 整体**；三层都未设置的素材**原地不动**——不缩放、不转码、
  不写出、不复制到输出目录，仅在报告中标为「未改动」。

**静态图片**

- 重采样算法可选：Lanczos3（默认）、Bicubic、Bilinear、Nearest。
- 按 EXIF 方向先旋转再缩放；保留 ICC 色彩配置。
- 保留基础 EXIF / XMP 并剥离缩略图等冗余数据，开关可控。
- 输出格式可保持原格式，或统一转换为 PNG / JPEG / WebP，并给出体积对比。
- SVG 双路径：输出仍为 SVG 时仅改写尺寸属性并同步 `viewBox`；输出为位图时按指定像素尺寸光栅化。
  未声明尺寸的 SVG 可在「直接填像素」与「按 DPI 换算」之间切换。
- 放大不会增加画面细节；放大倍率超过阈值（默认 4 倍，可调）时给出画质风险警告，但不阻止执行。

**视频**

- 编码器完整提供：H.264、H.265 / HEVC、VP9、AV1；默认 CRF 模式，另提供目标码率。
- 音频默认直接复制不重新编码；时长、帧率、字幕流与章节一并保留。
- 处理旋转元数据，输出观感方向与原视频一致；强制偶数宽高。
- HDR 默认原样传递不加任何色彩滤镜，另提供「色调映射到 SDR」。
- 硬件加速开关（NVENC / QSV / AMF），编码失败自动回退软件编码并在日志中记录。

**动图**

- 保留帧数、每帧延迟、循环次数、透明通道与帧偏移；每帧等比缩放保证帧间尺寸一致。
- 调色板颜色数可选 256 / 128 / 64，抖动可开关；支持转为 MP4 / WebM 并给出体积对比。

**输出与执行**

- 输出目录两种方式并存：默认在源文件夹同级建立 `output/`，也可每次任务单独指定；
  两者都不可写时明确提示并引导改用指定目录。
- 覆盖源文件默认关闭，开启后执行前弹出二次确认，列出将被覆盖的文件数量与路径。
- 同名冲突可选跳过（默认）/ 覆盖 / 自动重命名；保留相对目录结构；输出文件名保持原名。
- 可选「处理前备份源文件」；提供干跑模式（只计算与预览，不写出任何文件）。
- 写出后按输出格式校验能否正常解码，不合格的输出会删除并计入失败。
- 处理过程实时显示进度、可取消；单文件失败不中断整体，支持仅重试失败项。
- 执行前读取目标磁盘剩余空间，供与预计输出体积比对。

**体积目标**

以目标体积为约束时按阶梯逐级逼近，绝不无限循环：图片降质量 → 降尺寸；
动图减色数 → 降尺寸 → 丢帧；视频降质量 → 降尺寸 → 降帧率。
每档结果都会记录并展示；档位耗尽仍超标时保留其中体积最小的一次输出，并明确标注「未达标」。

**报告与日志**

- 执行结果按**成功 / 未改动 / 已跳过 / 失败**四类统计，失败与跳过项会逐条列在日志区；
  输出目录保持干净，只保留处理后的素材文件，不生成报告文件。
- 日志写入 `config/../logs/`，按日期滚动，保留 30 天。
- 增量处理：记录上次结果，可跳过未变化的素材（判定依据为体积 + 修改时间 + 设置指纹）。

**预设**

内置 1080P、720P、4K、1080×1920、1080×1080、1080×2640、2640×2640、640×640 八个预设；
内置预设可隐藏但不可删除，自定义预设可新增、重命名、删除，以 JSON 保存并支持导出与导入。

**界面**

- 分区：素材列表区、参数设置区、预览区、执行与进度区、日志区。
- 界面语言仅中文；支持浅色 / 深色主题，默认跟随系统。
- 可自定义主题色、界面密度，可用本地图片作界面背景并调节透明度与蒙层。
- 各分区可用标题栏的把手拖动重排、新建或合并列，列宽与列内高度可拖动，布局自动记住。

## FFmpeg

视频与动图处理依赖 FFmpeg。本项目采用 **GPL 构建的 FFmpeg，以独立进程方式调用**
（不链接、不修改其源码）。FFmpeg 二进制**不纳入版本控制**（体积较大）。

**放置路径：**

```
src-tauri/resources/ffmpeg/win-x64/
├── ffmpeg.exe
├── ffprobe.exe
├── libgcc_s_seh-1.dll
└── libwinpthread-1.dll
```

**获取方式：** 可用 `scripts/build-ffmpeg-gpl.sh` 自行构建。该脚本在 MSYS2 MINGW64 下运行，
产出 FFmpeg **9.0.2**，静态链接 libx264 / libx265 / libvpx / libaom / zimg / libwebp，
脚本头部写明了完整的依赖安装命令与注意事项。

运行时要求所用构建包含 `libx264`、`libx265`、`libvpx-vp9`、`libaom-av1` 编码器，
`palettegen`、`paletteuse`、`zscale`、`tonemap` 滤镜，以及 `hevc` 解码器。
程序启动时会自动自检，缺少组件会在界面与日志中给出明确提示，而不是静默禁用相关功能。
